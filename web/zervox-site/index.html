Auto-Fix Loop

Autonomous crash detection and AI-powered repair cycles that heal your apps in seconds. Just deploy and trust.

AI Diagnostics

Gemini AI analyzes crash logs, identifies root causes (missing modules, port conflicts, syntax errors), and suggests precise fix commands.

Global Daemon

Manage a swarm of processes across multiple environments with a single unified interface. Track PIDs, restart limits, and exponential backoff.

Real-Time Dashboard

Web dashboard with live process monitoring. View status, tail logs, and apply AI-suggested fixes with one click.

Systemd Integration

Generate systemd user services from any tracked process. Survive reboots and crashes transparently with zero config.

7KB Binary in Rust

Single lean binary with zero runtime dependencies. Installs in seconds, uses minimal memory, no Node.js or interpreter needed.

How It Works

From crash to fix in seconds — fully autonomous.

1

Watch

Zervox monitors your processes. Every crash is captured with the last 80 lines of logs.

2

Diagnose

Gemini AI identifies root causes — missing modules, port conflicts, syntax errors, or permissions.

3

Fix

Auto-applies safe repairs: npm/bun/pnpm install for missing dependencies. Or approve from the dashboard.

4

Restart

Zero-downtime restart with configurable delay and max retry count. Integrated with systemd.

Production Documentation.

Comprehensive guides on setting up autonomous agents, fine-tuning repair strategies, and scaling your SRE operations.

Security-first execution environment

Every fix is validated before execution. Rollback on failure. No remote code execution without explicit approval.

Native Gemini AI Integration

On-device Gemini AI analyzes crash patterns without sending logs to external servers. Full privacy, local execution.

CLI Reference

zervox check -- <cmd> Run once, summarize failures
zervox start -- <cmd> Watch with auto-restart
zervox start --detach --name <n> Background daemon
zervox add <name> -- <cmd> Save command
zervox status [name] Show runtime status
zervox logs <name> [-n N] Tail persistent logs
zervox stop <name> Stop process
zervox systemd <name> Generate systemd unit
zervox list List tracked commands
